# Chess Animation Studio 0.2.47

This update follows the editing workflow from opening a game through exporting a video. The walkthrough covered the nine settings panels, move playback, an empty storyboard, the export dialog, and a Shorts preview at 150% UI scale on a 1100 × 700 window.

| Workflow | What changed |
| --- | --- |
| Start a project | An empty game now offers **Import PGN or FEN** beside the board and explains how to enter a move directly. |
| Find a setting | **Ctrl+K** opens the settings search even when the sidebar is hidden. Use the arrow keys and Enter to reveal and focus the result. Search covers the current Full Game or Storyboard workspace. |
| Frame a video | **Output format** has a single home above the board. In narrow previews, **Tools** holds zoom, guides, and other viewing options. Fit, Full preview and Save PNG stay visible. In short windows, the center column scrolls to keep the timeline reachable. |
| Try a move preset | Cancel or close a preset preview to return to the original playhead. Keep using **Move frames** to inspect how an effect starts, peaks and lands. |
| Arrange the workspace | Workspace presets remember panel sizes and visibility. **Return to editing** brings back the previous layout after a large preview. Resize handles respond to directional arrow keys. |
| Edit a storyboard | The Timeline workspace keeps the storyboard open. Play restarts the composition when it reaches the end. |
| Export an MP4 | The dialog names the active game, move or storyboard range. Choose FFmpeg from the dialog when needed and open Files to relink missing media. Keyboard focus stays inside the dialog until it closes. |

This version also includes the thinner adjustable piece edges, the **Gray & white** board palette, and the **Player intro** photo overlay from the preceding update.
