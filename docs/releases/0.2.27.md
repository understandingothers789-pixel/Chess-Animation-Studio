# Chess Animation Studio 0.2.27 — Timeline context menus

Adds menus for move, camera, badge/effect, annotation and music tracks. Right-click a clip or use the track header menu to open the correct inspector, copy/paste move settings, adjust speed, toggle effects, edit or delete annotations, and control music/beat cues. Menus support keyboard navigation and stay within the window. Track visibility, zoom and snapping preferences persist, with a reset action. Music-driven dark-square pulse controls now live in Music alongside knight horse sound controls.
