# Chess Animation Studio 0.2.48

- Choose a preset, check the target and settings category, then replay the preset or play the original. Group previews use the same move scope and settings as Apply. Each application is a single Undo step.
- Use **Apply & fine-tune** to open the matching controls for the affected moves. **Advanced apply options** keeps custom curves and full replacement available. The move inspector links directly to saving the current settings as a reusable preset.
- Open **Move frames → Effect timing** to see where the starting-square meme, main movement, piece-size changes, after-effect, and any enabled beat zoom play. Click a timing bar to inspect its midpoint. Use **Tune** to open the exact controls for that effect.
