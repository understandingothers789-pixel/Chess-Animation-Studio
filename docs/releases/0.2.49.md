# Chess Animation Studio 0.2.49

- Open **Intro clip → Player intro** to import a player photo, choose **Spotlight reveal**, set the transition time, and add a subtitle. If a video pullback is enabled, the player appears after the board is revealed.
- Open **Intro clip → Video pullback** to import a clip, pick its board square, and adjust how long the close-up holds and how slowly the camera pulls back. Import uses FFmpeg to prepare the first three seconds without audio. Shorter video holds its last frame. Preview and Full Game MP4 export use the same prepared frames.
- Open **Starting-square meme → Crop and transition** to reposition and zoom an image inside the square or add a brief fade. The crop preview matches the square, and the move timing lock still protects the reserved time.
