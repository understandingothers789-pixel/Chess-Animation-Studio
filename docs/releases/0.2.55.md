# Chess Animation Studio 0.2.55

- Get a larger board preview on shorter windows and turn the selected move into a vertical storyboard.
- Apply only the preset components you want, compare matching frames, and pin a landing, capture impact, zoom peak, or after-effect to a music hit.
- Re-trim and crop an opening video from its original and review the full opening in the composition.
- Keep per-project recovery checkpoints. Editing one move or shot retains the unchanged project data.
- Display forced mates separately from pawn losses in Stockfish review.
- See estimated render time and reveal the finished MP4 from the export dialog.

Extract the ZIP and open `Chess Animation Studio.exe`. The release signature report and SHA-256 checksum are available alongside the ZIP.


## Windows publishing

Run **Windows portable build** with **publish_release** to upload a validated versioned ZIP and checksum. The workflow downloads both public assets and checks them against the local build before showing a direct link.

For a publisher-signed build, configure the Windows workflow with `STUDIO_SIGNING_PFX_BASE64` and `STUDIO_SIGNING_PFX_PASSWORD` secrets from a trusted code-signing credential and select **require_signature**. The package is created only after SignTool verifies the executable signature.
