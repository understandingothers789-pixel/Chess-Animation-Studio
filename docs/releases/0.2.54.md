# Chess Animation Studio 0.2.54

- Match both highlighted squares to the move badge automatically, with project and per-move overrides.
- Use a single question mark for reviewed moves that lose more than 0.50 pawns.
- Download and select the latest official Stockfish development build from Files. Studio installs it in Downloads / Stockfish Development and reuses verified builds.

Extract the ZIP and open `Chess Animation Studio.exe`. The executable is unsigned.
