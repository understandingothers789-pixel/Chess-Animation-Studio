# Chess Animation Studio 0.2.42

- Select a move and choose **Add animation or effect → Starting-square meme**. Import a local image or choose one from your project.
- The image fills the square the piece is about to leave. Studio center-crops it, hides the piece for the meme, and reveals the piece at departure. The normal move and capture effects then play.
- Set **Meme duration** and use **Preview meme on board** or the **Meme** thumbnail in **Move frames**. The meme uses existing departure delay first and adds more time when needed. A locked move can use time it already has.
- The meme appears in Full Game and Storyboard previews and MP4 exports. Relink moved image files in **Files**.
