# Chess Animation Studio 0.2.35

- Add a visible, editable caption at the playhead with one click in Full Game or Storyboard.
- Import or paste SRT, WebVTT, Whisper word JSON or whisper.cpp JSON. Click transcript words to seek, follow playback, search, adjust timing and correct text.
- Generate short captions with five words per phrase by default (configurable). Storyboard captions use output time and split at shot boundaries. Generated captions use the existing preview/export compositor, typography and positioning tools.
- Optional one-click Windows x64 Whisper setup downloads a pinned whisper.cpp executable and tiny English model from GitHub and verifies SHA-256 checksums. Recognition runs locally; recordings are not uploaded. Existing whisper-cli/model installations can also be selected.
- Caption generation is undoable, preserves manual layers and replaces only captions generated from that timeline's transcript. Saved projects retain transcripts. SRT/VTT cue timing is identified honestly; short phrase timing within cues is estimated.

See [caption usage and validation](../captions-035/REPORT.md). Windows downloads are added to the README after the packaged validation succeeds. No public release is published by branch pushes.
