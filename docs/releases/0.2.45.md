# Chess Animation Studio 0.2.45

- Every built-in move preset has a description in its selector, in the animation library, and on hover or keyboard focus in the preview pop-up.
- **Move → Movement → Preview move presets** opens an example capture rendered with the board’s current artwork. Try any preset, pause, restart, or scrub, then choose **Apply movement** to use it on the selected moves. Previewing leaves the composition unchanged. With reduced motion enabled, the demo opens paused.
- **Preview demo** on a built-in library card opens the same pop-up. The main card still previews the preset on the selected move. Closing the animation library clears its temporary preview.
