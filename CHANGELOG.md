# Version history

## 0.1.4 — portable Windows build

[Download portable Windows 0.1.4](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/windows-v0.1.4.zip). Restores the assemble-and-run download format and includes the Lichess Cburnett and Nibbler/Merida vector artwork from Nocturne Chess, rendered as higher-resolution textures. Piece sets can be selected in Design; board colors and dark-square music pulses remain configurable. The build and portable ZIP integrity check passed. Windows launch was not independently tested for this version. The pieces currently have flat faces during turns; restoring a solid thin edge remains unfinished.

## 0.1.3 — direct-layout download

[Download Windows 0.1.3](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/windows-v0.1.3.zip). Tried a download layout that reconstructs the executable directly instead of assembling a ZIP. The user reported that Windows Application Control still blocked it.

## 0.1.2 — versioned Windows build

[Download Windows 0.1.2](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/windows-v0.1.2.zip). Added a distinct application and download version number. The app remained unsigned; Windows Application Control could block it.

## 0.1.0 — initial build

[Download the initial portable bundle](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/portable-v0.1.0.zip). Initial desktop editor with chess animation, music, analysis, project saving, presentation and MP4 export. Earlier builds reused this version number, so not every 0.1.0 download has identical contents.
