# Chess Animation Studio 0.2.46

- Illustrated pieces have thinner edges by default during spins and flips. Set **Board & pieces → Edge depth** from 0 to 100%. The default is 40%. Set it to 100% for the previous depth.
- Choose **Board & pieces → Board palette → Gray & white** for a neutral board. Saved palettes and individual square color controls are preserved.
- Select **Intro → Player intro** and import a player photo. Add an optional name and choose Fade and rise, Gentle zoom, or Crossfade. Preview the photo and name over the center of the board before the first move. The effect respects image transparency and uses the Intro clip length.
- In Storyboard, turn on **Show player intro** for any position hold to use the configured photo and name. Both modes include the effect in MP4 exports.
