# Chess Animation Studio 0.2.34

- Select multiple local text layers with Shift/Ctrl/Command-click in the preview or layer list. Drag or nudge the selection together, align measured edges/centers, and distribute three or more layers with equal gaps.
- Group operations respect ownership, visibility, canvas locks and safe margins, and use one Undo transaction. Inspector settings edit the primary layer.
- Annotation gestures clone only their source/shot annotation list instead of cloning and comparing the entire game. Unrelated immutable branches and history snapshots remain isolated.
- Caption edits retain existing arrow and circle meshes. Geometry changes dispose the replaced resource and preserve unrelated shapes.
- Includes inherited-caption localization, nondestructive text visibility and canvas locks from the development branch.

Windows downloads require a successful packaged validation run. No public release is published automatically for branch pushes.
