# Generated validation projects

Open a `.castudio` file in Chess Animation Studio 0.2.31. Generated audio is included beside the files and project paths are relative. These are computational test fixtures: 0.3-second shots and 90×160 / 160×90 MP4s make exhaustive frame decoding practical. They are not examples of editorial reading time or final export quality.

The puzzle uses the legal Fool’s Mate line and its real checkmate. The caption stress project deliberately raises overflow warnings. The synchronization project uses output-time gain automation and beat-aligned cuts. `continuous.wav` is a generated 440 Hz tone; `rhythm.wav` supports the longer UI composition in the parent folder. No third-party music is used.
