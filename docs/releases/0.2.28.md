# Chess Animation Studio 0.2.28 — Scoped contextual editing

Adds category-specific copy/paste, counted chess-aware bulk application, keyboard-accessible secondary menus, a compact selection toolbar, and preview-board annotation/FEN/frame commands. Corrects timing-lock enforcement, right-click multi-selection, overlapping annotation duplicates, and beat creation outside the music lane. Camera copies target the active output configuration; Everything explicitly includes all formats. Locked timing is preserved and counted in bulk operations. Board picking uses the geometric board plane and is checked across orientation, tilted cameras, output formats, zoom and pan.

The optional command palette is deferred. Context-menu secondary choices use an in-place panel with Back/Left-arrow navigation, rather than pointer-hover flyouts. Existing camera keyframe channels remain shared across output formats; per-format camera configurations stay separate.
