# Chess Animation Studio 0.2.44

- Right-click a timeline move and choose **Starting-square meme…**. A dialog for that move opens with **Import meme image**, the project’s existing images, duration, and board preview. The crosshair appears during annotation drawing.
- Playing a different move on the preview board creates a variation. Use **Game line** above the board to return to **Main line** or jump to another version. Playing a move that already exists follows that line. Subsequent moves can extend an edited variation.
- Saving preserves each visited line’s move IDs, effects, timing, and analysis. Older saves with only the moves of an inactive line can still reconstruct its legal sequence.
- **Ctrl+Z** / **Ctrl+Shift+Z** on Windows undo and redo board edits. The Undo and Redo buttons remain available in the toolbar.
