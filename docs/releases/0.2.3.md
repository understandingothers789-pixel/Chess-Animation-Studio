Fresh implementation with Nocturne's sharp Nibbler/Merida and Lichess/Cburnett vector art, real thin solid edges, slow sway, a per-move editor, normalized keys, per-format camera/layout, music waveform and editable landing markers, local Stockfish/Masters suggestions, save/recovery, presentation, and direct H.264/AAC export.

Extract all files from `Chess-Animation-Studio-0.2.3-Windows-Portable.zip`, then open `Chess Animation Studio.exe`. No assembly script or source build is needed. Choose FFmpeg in Files to enable export; Stockfish is optional. Neither tool is bundled.

This release is published by the native Windows workflow only after its core/service tests and packaged-app desktop/export checks succeed. The runtime is copied byte-for-byte from the official Electron distribution. The executable's recorded Authenticode state is NotSigned; the app remains unsigned. Smart App Control approval on your PC is not guaranteed. No security settings or download metadata are changed.

Changes since the first fresh-build checkpoint include corrected image/audio asset separation, music playback checks, restored-file cache refreshes, safe save paths for new projects, reusable presets with an inline name field, live presentation updates, real-width ribbon trails, and adjustable badge glow.

The release includes the archive checksum and signature evidence. BUILD.json inside the portable folder records its source commit and runtime version. Detailed scope and limits are in docs/VALIDATION.md in the source. Elaborate portal scenes, cutaways, character props, and animated media remain later features.

Additional stability fixes: serialize recovery writes at close so a pending older snapshot cannot overwrite the final one; remove UCI wait listeners after each search; include the app version in the actual window title.
