# Chess Animation Studio 0.2.50

- In **Move frames → Effect timing**, drag a handle or focus it and press Enter to propose a change. Enter an exact value, choose a landing or beat zoom marker, and see the timing shift before applying. Timing locks are respected, and each application is one Undo step.
- Start an edited sequence with **+ Opening shot**. The shot uses the shared Intro clip and can be reordered or resized. Set the video's in-point and crop before importing or replacing it. A crop preview shows the first prepared frame.
- Open **Export MP4 → Preview selected export** to scrub the actual output frames, check caption safe areas, and jump to the intro, first capture, ending, or a timed caption warning.
