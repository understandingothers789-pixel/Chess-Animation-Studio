The main preview redraws when you play, seek, resize, edit, or load artwork. A paused preview now stops scheduling redraws once the frame settles.

The source timeline reuses timing, snap points, and the waveform path while the playhead moves. Move clips and storyboard thumbnails skip updates when their inputs stay the same. Move frames reuse their previews across play and pause. Artwork changes trigger fresh move and storyboard thumbnails.

Reload graphics now creates a fresh canvas after WebGL context loss. Saving a PNG restores the live preview immediately. Cancelling or restarting playback keeps older audio requests from starting late. Removed and replaced audio files cannot repopulate the cache from a late decode. Asset checks also avoid overlapping requests and ignore results from a previous project.

Windows export validation uses FFmpeg 9.0.2. The tested FFmpeg 9.1 Essentials build hung while mixing soundtrack audio. If you encounter that hang, select FFmpeg 9.0.2 in Studio.
