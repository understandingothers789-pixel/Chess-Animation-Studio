# Chess Animation Studio 0.2.59 for Windows x64

- Full preview opens portrait compositions enlarged for easier board inspection. Choose **Fit** to see the entire output frame. Exiting restores the editor viewport.
- Colored notation stays in the top-right of the destination square in either board orientation.
- The bundled Opera Game includes an offline Stockfish review, including brilliant marks for Nxb5 and Qb8+.

Extract the portable ZIP and open **Chess Animation Studio.exe**.
