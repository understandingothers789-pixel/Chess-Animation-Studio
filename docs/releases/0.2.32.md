# Chess Animation Studio 0.2.32

Adds per-shot music ducking in the storyboard inspector: enable, music level, fade down and fade up. A shared output-time envelope drives scheduled Web Audio playback, the waveform gain curve and FFmpeg export. Adjacent shots transition directly between levels, including interrupted ramps on short shots. Chess sound effects retain their independent gain.

Multiple-caption selection/resizing and transitions are deferred to keep this release focused.

See the [focused engineering report](../ducking-032/REPORT.md) for validation and build status.
