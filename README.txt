Chess Animation Studio v0.1.0 portable Windows x64 download

This GitHub branch carries the Windows app archive in parts because GitHub's regular source ZIP download cannot contain a single file larger than GitHub's file limit. These parts reconstruct the original app ZIP unchanged.

To install and launch:
1. In GitHub, choose Code > Download ZIP for the portable-v0.1.0 branch.
2. Extract that downloaded ZIP.
3. Double-click Assemble-and-run.cmd. It joins the parts, checks the SHA-256, extracts the app, and launches it.
4. Keep the extracted app folder together. Choose FFmpeg in Settings if you want to export MP4.

The portable app is unsigned. Windows may show its standard downloaded-app confirmation. This branch contains only the distribution parts and helper; the source is on the work branch.
