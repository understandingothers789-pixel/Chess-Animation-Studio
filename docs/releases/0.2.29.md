# Chess Animation Studio 0.2.29 — Hover flyouts and direct contextual editing

Replaces in-place secondary menus with real side-opening hover flyouts, keeps parents visible and highlighted, and supports pointer-safe diagonal transitions, keyboard navigation, viewport collision handling, and a compact fallback for constrained widths. Exact edit commands focus their requested controls. A compact bulk panel shows the source, settings category, chess-aware target group, affected count, and timing locks before applying one undoable operation.

Preview menus distinguish annotations, board squares, and empty background. Viewing commands keep playback running; editing pauses when chosen. Adds preview view/guide/fullscreen actions, asynchronous FEN-copy feedback and PNG download feedback. Corrects copied FEN to the position after the last landed move. Rendering and audio architecture remain intact. The selection toolbar focuses on Preview, Preset, Edit and More actions.

The optional command palette and customizable hover delay are deferred. PNG feedback confirms that the browser download started; final file placement is controlled by the browser or operating system. Camera keyframe channels retain the existing shared project model, while per-format configurations remain separate.
