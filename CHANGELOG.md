## 0.1.7 — original pieces with slow sway

## 0.1.6 — slow sway

**[Download 0.1.6 for Windows (unsigned, x64)](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/windows-v0.1.6.zip).** Replaces the fast Wiggle preset with Slow sway: one broad 24-degree lean each way over 2.2 seconds, smooth reversals, and an upright finish. Sway timing follows the full move duration. Angle, cycles, duration and keyframes remain editable. Reapply Slow sway to existing moves to use the new defaults. All 11 core animation/chess tests passed; build and ZIP integrity passed. Windows launch is unverified. Portable app ZIP SHA-256: `d70dd3616108f117bcb6d552a2bfff6de70ca0d9424bf7fbcbcad3a45ccfa5cd`.

## 0.1.4 — portable Windows build

[Download portable Windows 0.1.4](https://github.com/understandingothers789-pixel/Chess-Animation-Studio/archive/refs/tags/windows-v0.1.4.zip). Restores the assemble-and-run download format and includes the Lichess Cburnett and Nibbler/Merida vector artwork from Nocturne Chess, rendered as higher-resolution textures. Piece sets can be selected in Design; board colors and dark-square music pulses remain configurable. The build and portable ZIP integrity check passed. Windows launch was not independently tested for this version. The pieces currently have flat faces during turns; restoring a solid thin edge remains unfinished.
